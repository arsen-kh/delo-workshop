# Автоматизация отчёта из CSV

Самостоятельный учебный проект без внешних зависимостей. Нужен Node.js. Принимает одну или несколько выгрузок заявок, проверяет данные и создаёт HTML-отчёт и три CSV-файла.

## Пример запуска

Из корня исходного проекта:

```sh
node automation/report.mjs automation/examples/requests.csv automation/examples/extra-with-errors.csv --out report-output --from 2026-11-07 --to 2026-11-07
```

Результат: 7 корректных заявок, 2 закрытые, стоимость закрытых работ 8700 ₽, 1 идентичный дубль исключён, 1 ошибочная строка отклонена. Число просроченных зависит от даты запуска. Все данные вымышленные.

Выходные файлы:

- `report.html` — визуальный отчёт, открывается обычным браузером;
- `summary.csv` — показатели и распределение по статусам;
- `details.csv` — корректные заявки выбранного периода;
- `errors.csv` — источник, номер записи и причина отклонения.

Для своих данных скачайте детализацию из раздела «Заявки» или «Отчёты» сервиса. Поддерживаются UTF-8 с BOM или без, разделители `;` и `,`, кавычки и переносы строк внутри полей. Заголовки ожидаются по формату сервиса. Обязательные: «Номер», «Статус», «Ответственный», «Срок», «Стоимость, ₽», «Создана». Сумма — целое неотрицательное число в рублях. Дата создания — ISO с часовым поясом; срок — YYYY-MM-DD или пустое поле.

Параметры `--from` и `--to` необязательны. Фильтруется дата создания по Москве, границы включены. Статусы и срок относятся к состоянию выгрузки; это не отчёт о переходах статуса за период. Стоимость закрытых работ не является подтверждённой выручкой.

Идентичность дублей определяется по полям, влияющим на расчёт: номер, статус, ответственный, срок, стоимость, дата создания. Противоречивые версии одного номера останавливают расчёт: не смешивайте старую и новую выгрузку одних и тех же заявок. Синтаксически повреждённый CSV, отсутствие обязательных столбцов и некорректный период тоже останавливают расчёт. До записи результата разбираются все входные файлы. Для каждого запуска желательно использовать новый каталог `--out`, чтобы отличать результаты от предыдущего.

## Проверки

```sh
node --test automation/report.test.mjs
```

Тесты проверяют кавычки и переносы, дубли, противоречия, неверные суммы и даты, границу суток по Москве и защиту CSV-выгрузки от формул.

## Дальнейшее развитие

Универсальное сопоставление названий столбцов, загрузка XLSX, отчёты по истории статусов, периодический запуск и сравнение времени с ручной сборкой. Эти возможности пока не реализованы.
